假设 `list1 = [1, 2, 3]`：

```python
for i in range(len(list1)):
```

```python
if i == len(list1) - 1:

```

列表下标从 `0` 开始，所以最后一个下标是 `len(list1) - 1`。输出最后一个数字时，`print()` 默认在末尾换行。

```python
else:
    print(list1[i], end=" ")
```

其他数字输出后加一个空格，继续在同一行输出下一个数字。`end=" "` 将默认的换行改成了空格。

最终输出：

```text
1 2 3
```

因此，`if/else` 的作用是分别处理“最后一个数字”和“前面的数字”，避免末尾多出空格。
